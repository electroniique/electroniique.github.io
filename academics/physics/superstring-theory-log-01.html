[hep-ex/0008017] Introduction to Superstring Theory 학습 로그 (1)

1. STRING THEORY의 기본 관점

일반적인 입자물리학에서는 기본 입자를 0차원의 point particle로 취급한다. 입자가 시간에 따라 이동하면 1차원의 world-line을 만든다.

String theory에서는 기본적인 물체를 1차원의 string으로 본다. String이 시간에 따라 움직이면 2차원의 world-sheet를 만든다.

point particle → world-line
string → world-sheet

String에는 open string과 closed string이 있으며, string의 서로 다른 진동 상태가 저에너지에서는 서로 다른 종류의 입자로 나타난다.

특히 closed string의 spectrum에는 massless spin-2 state가 존재하며, 이를 graviton으로 해석할 수 있다. 이것이 string theory가 quantum gravity의 후보가 되는 핵심 이유 중 하나다.

2. BOSONIC STRING THEORY

Bosonic string theory는 가장 단순한 양자 string theory다.

World-sheet 위의 기본적인 장 X^μ(τ,σ)는 string의 시공간에서의 위치를 나타낸다.

Bosonic string theory에는 open string과 closed string이 존재하며, closed-string spectrum에는 graviton에 해당하는 massless spin-2 state가 나타난다.

그러나 세 가지 중요한 문제가 있다.

첫째, spacetime fermion이 없다.
둘째, tachyon이 존재하여 vacuum instability를 나타낸다.
셋째, 일관된 양자이론을 위해 26차원이 필요하다.

이러한 문제들을 해결하는 방향에서 superstring theory가 등장한다.

3. SUPERSYMMETRY

Supersymmetry(SUSY)는 boson과 fermion을 연결하는 symmetry다.

Q|B> ~ |F>
Q|F> ~ |B>

여기서 Q를 supercharge라고 한다.

Supercharge는 supersymmetry transformation의 generator이며, SUSY algebra는 schematic하게

{Q,Q†} ~ P_μ

형태를 갖는다.

즉 두 번의 SUSY transformation이 spacetime translation과 연결된다.

일반적인 연속 대칭에서 generator가 infinitesimal transformation을 생성하는 것처럼, SUSY에서는 fermionic generator Q가 boson과 fermion 사이의 transformation을 생성한다.

“Super”라는 표현은 단순히 매우 강한 symmetry라는 뜻이 아니다. 일반적인 Lie algebra를 bosonic generator뿐 아니라 fermionic generator까지 포함하는 Lie superalgebra로 확장한다는 의미다.

정확한 SUSY가 존재한다면 같은 supermultiplet에 속한 boson과 fermion은 같은 질량을 가져야 한다. 현재 그러한 superpartner는 관측되지 않았으므로, 자연에 SUSY가 존재한다면 accessible energy scale에서는 broken되어 있어야 한다.

4. RNS와 GREEN-SCHWARZ FORMULATION

Superstring theory를 기술하는 대표적인 두 formulation이 RNS와 Green-Schwarz formulation이다.

RNS는 Ramond-Neveu-Schwarz formulation이다. 기본 변수로 X^μ와 ψ^μ를 사용하며 world-sheet supersymmetry가 명시적으로 나타난다.

Fermion의 boundary condition에 따라 NS sector와 R sector가 생긴다.

대략적으로

NS sector → spacetime bosons
R sector → spacetime fermions

으로 연결된다.

GSO projection을 적용하면 일관된 supersymmetric spectrum을 얻을 수 있다.

Green-Schwarz formulation에서는 X^μ와 θ^α를 사용한다. 여기서는 spacetime supersymmetry가 보다 직접적으로 나타나지만 covariant quantization은 더 어렵다.

5. MINKOWSKI METRIC

특수상대론의 평평한 spacetime은 Minkowski metric η_μν으로 기술된다.

대표적인 convention은

η_μν = diag(1,-1,-1,-1)

이다.

따라서 spacetime interval은

ds² = c²dt² - dx² - dy² - dz²

이다.

Metric은 vector의 index를 올리고 내리는 역할도 한다.

V_μ = η_μν V^ν

예를 들어

V^μ = (V^0,V^1,V^2,V^3)

이면

V_μ = (V^0,-V^1,-V^2,-V^3)

가 된다.

4-momentum은

p^μ = (E/c, p)

이고 Minkowski inner product를 계산하면

p^μ p_μ = E²/c² - p² = m²c²

이므로

E² = p²c² + m²c⁴

를 얻는다.

6. COVARIANT / CONTRAVARIANT VECTOR

Contravariant vector component는 v^i로 나타낸다.

Coordinate transformation에서

v’^i = (∂x’^i/∂x^j)v^j

처럼 변환된다.

Covector는 dual space V*의 원소이며 ω_i로 나타낸다.

ω’_i = (∂x^j/∂x’^i)ω_j

처럼 변환된다.

Covector와 vector를 contraction하면

ω_i v^i

라는 coordinate-independent scalar가 된다.

Metric을 사용하면

v_i = g_ij v^j
v^i = g^ij v_j

와 같이 vector와 covector를 서로 대응시킬 수 있다.

7. COMPACTIFICATION

Superstring theory는 일관성을 위해 10차원 spacetime을 요구한다. 하지만 우리가 거시적으로 관측하는 spacetime은 3+1차원이다.

이를 연결하는 기본적인 아이디어가 compactification이다.

전체 spacetime을 대략

M_10 ≈ M_3,1 × K_6

로 생각한다.

M_3,1은 관측되는 4차원 spacetime이고 K_6은 매우 작은 6차원 compact space다.

가장 단순한 예로 하나의 extra dimension y를 원으로 compactification하면

y ~ y + 2πR

이다.

이는 공간을 외부의 더 높은 차원에서 실제로 접는다는 의미가 아니라 y와 y+2πR을 동일한 점으로 identification한다는 의미다.

8. KALUZA-KLEIN MODES

Compact dimension이

y ~ y + 2πR

이면 field는 periodic해야 한다.

Φ(x,y+2πR) = Φ(x,y)

따라서 Fourier expansion이 가능하다.

Φ(x,y) = Σ_n φ_n(x)e^(iny/R)

Compact direction의 momentum은 연속적이지 않고

p_y = n/R

로 quantized된다.

이를 Kaluza-Klein(KK) modes라고 한다.

Higher-dimensional energy-momentum relation을 4차원에서 보면

m_n² = m_0² + n²/R²

이 된다.

즉 하나의 higher-dimensional field가 4차원에서는 서로 다른 질량을 가진 무한한 field tower로 나타난다.

n = 0, ±1, ±2, …

n=0은 zero mode다.

9. 왜 작은 EXTRA DIMENSION을 볼 수 없는가?

Compactification scale이 R일 때

E << 1/R

이면 nonzero KK mode를 excitation하기 어렵다.

파동의 관점에서는

λ >> R

이므로 파동이 compact dimension의 세부 구조를 resolve하지 못한다.

따라서 낮은 에너지에서는 higher-dimensional theory가 효과적으로 4차원 theory처럼 보인다.

E << 1/R → 4D effective field theory

반대로

E ~ 1/R

에 도달하면 KK modes가 중요해지고 extra dimension의 존재를 감지할 수 있다.

더 높은

E ~ M_s = 1/sqrt(α’)

에서는 string 자체의 excitation이 중요해진다.

Compactification geometry는 단순히 차원의 수만 줄이는 것이 아니라 4차원에서 나타나는 particle spectrum, gauge symmetry, coupling, residual supersymmetry 등에 영향을 줄 수 있다.

10. P-BRANES

p-brane은 공간적으로 p차원인 extended object다.

p=0 → point particle
p=1 → string
p=2 → membrane
p=3 → 3-brane

시간을 포함하면 p-brane의 world-volume은 p+1차원이다.

예를 들어 string은 1차원 물체이므로 2차원 world-sheet를 만들고, 3-brane은 4차원 world-volume을 만든다.

11. D-BRANES

D-brane의 D는 Dirichlet을 의미한다.

Open string의 endpoint에는 대표적으로 Neumann boundary condition과 Dirichlet boundary condition을 줄 수 있다.

Neumann boundary condition에서는 endpoint가 해당 방향으로 움직일 수 있다.

Dirichlet boundary condition에서는 endpoint의 해당 coordinate가 고정된다.

D(p)-brane에서는 endpoint가 p개의 spatial direction에서는 자유롭게 움직이고 나머지 transverse direction에서는 고정된다.

따라서 endpoint가 움직일 수 있는 p차원 부분공간이 D(p)-brane이다.

예를 들어 x,y 방향에서는 자유롭고 z=z_0로 고정되어 있다면 endpoint는 2차원 평면에서 움직인다. 이것이 D2-brane의 직관적인 예다.

모든 spatial direction이 고정되어 endpoint가 한 점에만 존재할 수 있다면 D0-brane에 해당한다.

모든 D(p)-brane은 p-brane이지만 모든 p-brane이 D-brane인 것은 아니다.

또한 D-brane은 단순한 boundary condition만을 의미하지 않는다. 실제로 tension과 RR charge를 가지며 움직이고 상호작용할 수 있는 dynamical object다.

12. D3-BRANE과 4D GAUGE THEORY

D3-brane은 공간적으로 3차원이다.

따라서 world-volume은 3+1=4차원이다.

D3-brane에 붙어 있는 open string의 excitation은 이 4차원 world-volume을 따라 전파될 수 있다.

Open string의 massless bosonic state 중에는 spin-1 vector state가 있으며, D3-brane 위에서는 A_μ(x)라는 gauge field로 나타난다.

open-string massless vector mode
→ A_μ
→ 4D gauge theory

하나의 D3-brane에서는 저에너지에서 대략 U(1) gauge theory가 나타난다.

13. 여러 D3-BRANES와 NON-ABELIAN GAUGE THEORY

N개의 D3-brane을 겹쳐 놓으면 open string의 한쪽 끝은 i번째 brane에, 다른 끝은 j번째 brane에 붙을 수 있다.

따라서 open-string state에는 N×N 구조가 생기며 gauge field 역시

A_μ^i_j

와 같은 matrix-valued field가 된다.

그 결과

N coincident D3-branes → U(N) non-Abelian gauge theory

가 나타난다.

Type IIB superstring theory의 D3-brane에서는 저에너지 world-volume theory가

4D N=4 supersymmetric Yang-Mills theory

가 된다.

전체 흐름은

D3-brane
→ 4D world-volume
→ open strings
→ massless vector modes
→ 4D gauge theory

이다.

14. OPEN STRINGS와 CLOSED STRINGS

D-brane이 존재할 때 중요한 구조는 다음과 같다.

open strings → D-brane world-volume의 gauge fields

closed strings → bulk를 전파하며 gravity를 포함

즉 string theory에서는 gauge theory와 gravity가 각각 open-string sector와 closed-string sector에서 자연스럽게 나타난다.

15. HIERARCHY PROBLEM

표준모형의 electroweak scale은 약 246 GeV인 반면 gravitational scale은 대략 10^19 GeV 정도다.

따라서 두 scale 사이에는 약 10^17 정도의 매우 큰 hierarchy가 존재한다.

단순히 두 숫자가 다르다는 것 자체보다 중요한 것은 Higgs가 elementary scalar field라는 점이다.

Higgs mass parameter는 heavy physics와의 interaction에 의해 schematic하게

δm_H² ~ (g²/16π²)M²

같은 quantum correction을 받을 수 있다.

그러면

m_physical² = m_bare² + δm_H²

에서 매우 큰 값들이 정밀하게 상쇄되어 작은 electroweak scale을 만들어야 할 수 있다.

이를 hierarchy 또는 naturalness problem이라고 한다.

SUSY에서는 bosonic loop와 fermionic loop가 서로 반대 부호의 correction을 만들어 큰 quantum correction을 상쇄할 수 있다.

따라서 electroweak scale을 안정화하는 것은 low-energy supersymmetry의 역사적으로 중요한 동기 중 하나다.

16. GRAND UNIFICATION

표준모형의 gauge group은

SU(3)_C × SU(2)_L × U(1)_Y

이다.

Grand Unified Theory(GUT)는 이것을 하나의 더 큰 gauge group G_GUT 안에 통합하려는 이론이다.

대표적인 예는

SU(5)
SO(10)
E6

등이다.

예를 들어 SU(5) GUT에서는 높은 에너지에서 SU(5)라는 하나의 symmetry가 존재하다가 낮은 에너지에서

SU(5) → SU(3)_C × SU(2)_L × U(1)_Y

로 symmetry breaking된다고 본다.

GUT에서는 quark와 lepton을 더 큰 gauge-group representation 안에 함께 넣을 수 있다.

Gauge couplings g_1, g_2, g_3는 energy scale에 따라 변하며, GUT에서는 매우 높은 에너지에서 이 coupling들이 하나의 값으로 통일되는 것을 기대한다.

Supersymmetric extension에서는 이러한 gauge coupling unification이 더 잘 맞는다는 것이 SUSY의 또 다른 역사적 동기였다.

GUT에서는 quark와 lepton 사이의 변환이 가능해질 수 있기 때문에 proton decay가 중요한 실험적 signature가 된다.

GUT는 strong, weak, electromagnetic interaction의 통일을 목표로 하지만 일반적으로 gravity까지 포함하지는 않는다.

17. STRING THEORY와 GRAND UNIFICATION

String theory에서는 큰 gauge group이 이론 자체의 구조에서 나타날 수 있다.

특히 heterotic string에서는

SO(32)

또는

E8 × E8

gauge group이 등장한다.

Compactification과 symmetry breaking을 통해

E8 → G_GUT → SU(3)_C × SU(2)_L × U(1)_Y

같은 구조를 생각할 수 있다.

따라서 string theory에서는 quantum gravity와 gauge interactions를 하나의 framework 안에서 다룰 가능성이 생긴다.

18. PERTURBATIVE STRING THEORY

Perturbation theory는 작은 coupling g가 있을 때 정확한 답을 작은 correction들의 급수로 근사하는 방법이다.

A(g) = A_0 + gA_1 + g²A_2 + …

QFT에서는 이것이 Feynman diagram의

tree → 1-loop → 2-loop → …

전개로 나타난다.

String theory에서는 이에 대응하는 것이 world-sheet topology다.

Closed oriented string의 경우 가장 단순한 world-sheet는 sphere이고 다음 correction은 torus다.

sphere → torus → two handles → …

즉

world-sheet genus ↔ loop order

라는 대응이 존재한다.

String interaction strength는 g_s라는 string coupling으로 나타낸다.

Closed oriented string amplitude는 schematic하게

A = Σ_h g_s^(2h-2) A_h

와 같은 genus expansion을 갖는다.

따라서 g_s << 1이면 higher-genus contribution이 억제되어 perturbative expansion이 유효하다.

19. DILATON과 STRING COUPLING

String theory에는 dilaton Φ라는 scalar field가 존재한다.

String coupling은 dilaton의 vacuum expectation value와

g_s = e^(<Φ>)

로 연결된다.

따라서 g_s는 단순히 외부에서 임의로 주어진 constant가 아니라 string theory 내부의 field configuration과 연결되어 있다.

20. NON-PERTURBATIVE STRING THEORY와 DUALITY

Perturbative string theory는

g_s << 1

일 때 유효하다.

하지만 g_s가 1에 가까워지거나 그보다 커지면 higher-order contribution을 무시할 수 없기 때문에 단순한 perturbative expansion만으로 전체 이론을 기술하기 어렵다.

1990년대의 Second Superstring Revolution에서는 서로 다른 superstring theories 사이의 duality와 D-brane 같은 non-perturbative object의 중요성이 밝혀졌다.

다섯 가지 perturbative superstring theory는

Type I
Type IIA
Type IIB
SO(32) heterotic
E8 × E8 heterotic

이다.

이들은 완전히 독립된 이론들이 아니라 duality를 통해 서로 연결되어 있다는 것이 밝혀졌다.

특히 S-duality는 어떤 이론의 strong-coupling regime을 다른 description의 weak-coupling regime과 연결한다.

또한 Type IIA string theory의 strong-coupling limit에서는 새로운 11번째 차원이 나타나는 것으로 해석된다.

Type IIA at strong coupling → 11D M-theory

이로부터 다섯 superstring theories와 11차원 supergravity가 더 근본적인 하나의 구조인 M-theory의 서로 다른 limit일 가능성이 제시된다.

21. 전체 개념 지도

현재까지의 내용을 하나의 흐름으로 정리하면 다음과 같다.

Point particle theory
→ String theory
→ closed string에서 graviton과 gravity 등장
→ open string에서 gauge field 등장
→ Supersymmetry
→ Superstring theory
→ 10D spacetime
→ Compactification
→ 4D effective theory와 KK modes
→ p-branes와 D-branes
→ D3-branes
→ 4D gauge theory
→ perturbative expansion in g_s
→ strong-coupling / non-perturbative physics
→ dualities와 D-branes
→ M-theory

가장 중요한 관계를 압축하면 다음과 같다.

closed strings → gravity

open strings on D-branes → gauge theory

compactification → higher-dimensional theory에서 4D effective physics로 연결

g_s << 1 → perturbative string theory

g_s가 커짐 → non-perturbative physics가 중요해짐

dualities + D-branes → 서로 다른 superstring theories의 연결

Type IIA strong coupling → 11D M-theory

현재 단계에서는 세부적인 수학적 유도보다 이 개념들의 논리적 연결 관계를 이해하는 것이 중요하다.

이후에는 world-sheet action, boundary conditions, string quantization, free-string spectrum, R/NS sectors, GSO projection, T-duality, anomaly cancellation, D-brane dynamics 등을 순서대로 연결하면 된다.
